# Rock-Paper-Scissors Game

## Overview
This is a simple interactive Rock-Paper-Scissors game built using **HTML**, **CSS**, and **JavaScript**. Players can compete against the computer and test their luck and strategy in this classic game!

Demo : https://guileless-florentine-6965df.netlify.app/

## Features
- User-friendly and responsive interface.
- Real-time game results and score tracking.
- Randomized computer choices ensuring fairness.
- Basic animations for an engaging experience.

## How to Play
1. Open the game in your browser.
2. Select one of the options: Rock 🪨, Paper 📄, or Scissors ✂️.
3. The computer will randomly select its move.
4. The game determines the winner based on the classic rules:
   - Rock beats Scissors.
   - Scissors beat Paper.
   - Paper beats Rock.
5. The scores update in real-time, and the winner is displayed after each round.

## Technologies Used
- **HTML**: Structure of the application.
- **CSS**: Styling and layout.
- **JavaScript**: Game logic and interactivity.

## Setup and Installation
1. Clone this repository to your local machine.
2. Open `index.html` in any modern web browser.
3. Play and enjoy!
